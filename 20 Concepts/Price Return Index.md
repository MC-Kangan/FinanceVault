## Level 1 - Foundation

### Formula and mechanics

**Equity Investments — Security Market Indexes:** An index contains constituent securities and uses a divisor. Visually verified: $PR_1=(V_1-V_0)/V_0=\sum_iw_iPR_i$; $TR_1=(V_1-V_0+D_1)/V_0=\sum_iw_iTR_i$. Indexes gauge sentiment, benchmark managers, proxy for asset classes/systematic risk, and support index products.[^eq-l1-p21]

### Equity slide enrichment

Price return excludes distributions, whereas total return includes them:[^eq-enrich-p21]

$$
PR_1=\frac{V_1-V_0}{V_0}=\sum_{i=1}^{n}w_iPR_i
$$[^eq-enrich-p21]

$$
TR_1=\frac{V_1-V_0+D_1}{V_0}=\sum_{i=1}^{n}w_iTR_i
$$[^eq-enrich-p21]

Consequently, the total-return index exceeds the price-return index over time under the source comparison.[^eq-enrich-p21]
