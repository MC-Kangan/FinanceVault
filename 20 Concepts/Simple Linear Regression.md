# Simple Linear Regression

> [!summary]
> Simple linear regression models a dependent variable as a linear function of one independent variable plus an error term.[^quant-l1-p52]

## Level 1 - Foundation

### Formula and mechanics

Simple linear regression models a dependent variable as a linear function of one independent variable plus an error term.[^quant-l1-p52]

### Interpretation

Use this concept within [[Quant - Simple Linear Regression]] and distinguish its role from neighbouring measures or methods before applying a formula.[^quant-l1-p52]

### Common pitfalls
