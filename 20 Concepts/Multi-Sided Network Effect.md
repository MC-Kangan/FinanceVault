# Multi-Sided Network Effect

> [!summary]
> A network effect connecting two or more participant groups whose growth increases value for other sides. It is a distinct Level 1 link target within [[Corporate Issuers]].[^ci-l1-p44]

### Definition and mechanics

<!-- enrichment:corporate-issuers:start -->

### Slide-level enrichment

Business-model variations include private-label/contract manufacturing, licensing, franchises, and value-added reselling. Platforms benefit from network effects: one-sided effects strengthen within one user group, while two- or multi-sided effects connect participant groups whose participation raises value for the others. Crowdsourcing makes users direct contributors to the product or service.[^ci-l1-p44]
