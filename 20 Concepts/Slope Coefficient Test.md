# Slope Coefficient Test

> [!summary]
> A slope coefficient test assesses whether the independent variable has a statistically significant linear relation with the dependent variable.[^quant-l1-p57]

## Level 1 - Foundation

### Formula and mechanics

A slope coefficient test assesses whether the independent variable has a statistically significant linear relation with the dependent variable.[^quant-l1-p57]
